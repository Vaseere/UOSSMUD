# UOSSMUD---GUI


# Chat
The Chat functions provide an interface for routing text into the GUI's tabbed chat container from triggers, aliases, and other scripts. Messages can be sent as plain text, CEcho-formatted text, or DEcho-formatted text, and are automatically copied to the All tab as well as the specified channel tab when one exists. The DEcho input can also detect a channel from a message formatted with a `[Channel]` prefix, making it particularly useful for directly forwarding captured MUD output. Additional functions allow scripts to switch the active chat tab or clear the contents of a specific channel.

| Function Name      | Function                            | Description                                                                                                                                                                                            |
| ------------------ | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Plain Chat         | `UOSS.GUI.addChat(channel, text)`   | Adds plain text to the specified Chat tab and the All tab. If the specified channel does not exist, the message is placed in the All tab.                                                              |
| Color Chat         | `UOSS.GUI.cechoChat(channel, text)` | Adds CEcho-formatted text to the specified Chat tab and the All tab. Supports Mudlet color tags such as `<red>`, `<green>`, and `<reset>`.                                                             |
| Decimal Color Chat | `UOSS.GUI.dechoChat(channel, text)` | Adds DEcho-formatted text to the specified Chat tab and the All tab. If the channel argument is omitted, the function attempts to determine the destination tab from a `[Channel]` tag in the message. |
| Select Chat Tab    | `UOSS.GUI.setChatTab(channel)`      | Changes the currently displayed Chat tab to the specified channel.                                                                                                                                     |
| Clear Chat Tab     | `UOSS.GUI.clearChat(channel)`       | Clears the contents of the specified Chat tab.                                                                                                                                                         |

# Status Effects
The Status Effects functions provide a simple interface for managing the Positive and Negative Effects panels from triggers, aliases, or other scripts. Effects can be added or removed individually by name, or entire groups can be supplied as slash-separated status strings using the abbreviations reported by the MUD. The mixed `setStatusEffects()` function is intended for complete status-line updates, automatically identifying each abbreviation as a positive or negative effect and replacing the contents of both panels accordingly. Separate functions are also available when only positive or negative effects need to be updated, as well as utility functions for removing specific effects or clearing one or both panels entirely.

$${\color{red}\text{WARNING: The Status Effect widget only works with the short version of the HP Bar tokens.}}$$

| Function Name            | Function                                                        | Description                                                                                                                                                                                                                                                                                          |
| ------------------------ | --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mixed Status Effects     | `UOSS.GUI.setStatusEffects(effectString)`                       | Replaces the current status effects using a mixed slash-separated string. Automatically determines whether each abbreviation is positive or negative and places it in the appropriate panel. Example: `Pr/Sh/Poi` places Protect and Shell under Positive Effects and Poison under Negative Effects. |
| Add Status Effect        | `UOSS.GUI.addStatusEffect(effectType, effectName)`              | Adds a single status effect to the specified panel. `effectType` may be `"positive"` or `"negative"`.                                                                                                                                                                                                |
| Add Positive Effect      | `UOSS.GUI.addPositiveEffect(effectName)`                        | Adds a single effect directly to the Positive Effects panel.                                                                                                                                                                                                                                         |
| Add Negative Effect      | `UOSS.GUI.addNegativeEffect(effectName)`                        | Adds a single effect directly to the Negative Effects panel.                                                                                                                                                                                                                                         |
| Set Positive Effects     | `UOSS.GUI.addPositiveEffectsFromString(effectString)`           | Replaces the current Positive Effects with a slash-separated status string such as `Pr/Sh/Reg`. Status abbreviations are expanded to their full names.                                                                                                                                               |
| Set Negative Effects     | `UOSS.GUI.addNegativeEffectsFromString(effectString)`           | Replaces the current Negative Effects with a slash-separated status string such as `Poi/Slw/Sil`. Status abbreviations are expanded to their full names.                                                                                                                                             |
| Set Effects by Type      | `UOSS.GUI.addStatusEffectsFromString(effectType, effectString)` | Replaces all effects of the specified type using a slash-separated status string. `effectType` may be `"positive"` or `"negative"`.                                                                                                                                                                  |
| Remove Status Effect     | `UOSS.GUI.removeStatusEffect(effectType, effectName)`           | Removes a single status effect from the specified Positive or Negative panel.                                                                                                                                                                                                                        |
| Remove Positive Effect   | `UOSS.GUI.removePositiveEffect(effectName)`                     | Removes a single effect from the Positive Effects panel.                                                                                                                                                                                                                                             |
| Remove Negative Effect   | `UOSS.GUI.removeNegativeEffect(effectName)`                     | Removes a single effect from the Negative Effects panel.                                                                                                                                                                                                                                             |
| Clear Positive Effects   | `UOSS.GUI.clearPositiveEffects()`                               | Removes all effects currently displayed in the Positive Effects panel.                                                                                                                                                                                                                               |
| Clear Negative Effects   | `UOSS.GUI.clearNegativeEffects()`                               | Removes all effects currently displayed in the Negative Effects panel.                                                                                                                                                                                                                               |
| Clear All Status Effects | `UOSS.GUI.clearStatusEffects()`                                 | Removes all positive and negative status effects from both panels.                                                                                                                                                                                                                                   |

# Status Bar

The Status Bar widget functions provide a common interface for feeding game data into the individual widgets displayed in the configurable status bar. Each widget exposes one or more setter functions appropriate to the information it tracks, such as gauges, counters, percentages, class resources, active modes, or parsed status strings. These functions are intended to be called from Mudlet triggers, aliases, or other scripts whenever new character data is received, allowing the visual widgets to update independently of the code responsible for capturing that data. Some widgets also provide more specific setters for updating only part of their state when a full update is not necessary.

### General Widgets

| Function Name                  | Function                               | Description                                                                 |
| ------------------------------ | -------------------------------------- | --------------------------------------------------------------------------- |
| Hit Points (HP)                | `UOSS.GUI.setHP(current, maximum)`     | Updates the current and maximum HP values for the Hit Points widget.        |
| Hit Points (Current)           | `UOSS.GUI.setCurrentHP(value)`         | Updates only the current HP value while preserving the existing maximum HP. |
| Hit Points (Maximum)           | `UOSS.GUI.setMaximumHP(value)`         | Updates only the maximum HP value while preserving the existing current HP. |
| Hit Points (Percentage)        | `UOSS.GUI.setHPPercentage(percentage)` | Updates the HP widget using a percentage value.                             |
| Magic Points (MP)              | `UOSS.GUI.setMP(current, maximum)`     | Updates the current and maximum MP values for the Magic Points widget.      |
| Magic Points (Current)         | `UOSS.GUI.setCurrentMP(value)`         | Updates only the current MP value while preserving the existing maximum MP. |
| Magic Points (Maximum)         | `UOSS.GUI.setMaximumMP(value)`         | Updates only the maximum MP value while preserving the existing current MP. |
| Magic Points (Percentage)      | `UOSS.GUI.setMPPercentage(percentage)` | Updates the MP widget using a percentage value.                             |
| Experience Points (XP)         | `UOSS.GUI.setXP(current, maximum)`     | Updates the current and maximum XP values for the Experience Points widget. |
| Experience Points (Current)    | `UOSS.GUI.setCurrentXP(value)`         | Updates only the current XP value while preserving the existing maximum XP. |
| Experience Points (Maximum)    | `UOSS.GUI.setMaximumXP(value)`         | Updates only the maximum XP value while preserving the existing current XP. |
| Experience Points (Percentage) | `UOSS.GUI.setXPPercentage(percentage)` | Updates the XP widget using a percentage value.                             |
| Ability Points (AP)            | `UOSS.GUI.setAP(current, maximum)`     | Updates the current and maximum AP values for the Ability Points widget.    |
| Ability Points (Current)       | `UOSS.GUI.setCurrentAP(value)`         | Updates only the current AP value while preserving the existing maximum AP. |
| Ability Points (Maximum)       | `UOSS.GUI.setMaximumAP(value)`         | Updates only the maximum AP value while preserving the existing current AP. |
